# November Content SPIFF — partner terms page

Static page with the terms of Amplemarket's November 2026 Content SPIFF for partners. Same setup as `summer-trial-sprint`.

- `index.html`, `styles.css`: the page (built with the playbook-to-website template)
- `script.js`: sidebar navigation, scroll highlighting and mobile menu only
- `fonts/`, `images/`: font, logo and background, served from this repo

No cookies, analytics, third-party scripts or forms. Outbound links go to public amplemarket.com pages and the application Google Form.

Owner: Partnerships (partners@amplemarket.com)
